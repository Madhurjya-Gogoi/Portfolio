# Madhurjya Gogoi — Portfolio

Built with Vite + React + TypeScript + Tailwind CSS v4. Compiles to static
files, so it deploys anywhere (Vercel, Netlify, Cloudflare Pages, GitHub
Pages).

## Before you deploy

A few placeholders need your real info — search for `TODO` or check:

- `src/components/Repos.tsx` — your GitHub username and real side-project repos
- `src/components/Contact.tsx` — your email, LinkedIn, and GitHub URLs

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
```

Output goes to `dist/`. Drag that folder into Netlify, or connect the repo
to Vercel/Cloudflare Pages for auto-deploys on every push.

## Design

Blueprint/survey-drawing motif, tying into the Urban Compass Software (GIS)
project: deep navy background, cyan-blue gridlines, amber accent, contour-line
section dividers, corner-bracketed project cards, and a coordinate stamp
(26.1445° N, 91.7362° E — Guwahati) in the hero.
